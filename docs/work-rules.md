# 株式会社しろくま堂システムズ 就業規則

> この文書は、QAボットの学習用に作成した架空の会社の規則です。実在の会社・規則とは関係ありません。

## 第1章 総則

### 第1条(目的)

この規則は、株式会社しろくま堂システムズ(以下「会社」という)の従業員の労働条件と、服務に関する事項を定めるものである。

### 第2条(適用範囲)

この規則は、会社と期間の定めのない労働契約を結んだ正社員に適用する。契約社員とアルバイトには、この規則のうち第3章(勤務時間・休日)と第4章(休暇)のみを適用し、その他の事項は個別の雇用契約書で定める。

### 第3条(試用期間)

1. 新たに採用した者には、入社日から4か月の試用期間を設ける。
2. 会社は、本人の適性を判断するために必要な場合、試用期間を最大2か月延長できる。延長するときは、試用期間が終わる日の2週間前までに本人に書面で通知する。
3. 試用期間は勤続年数に含める。

## 第2章 服務

### 第4条(服務規律)

従業員は、次の事項を守らなければならない。

1. 業務上知り得た会社と取引先の情報を、在職中・退職後を問わず外部に漏らさないこと。
2. 会社が貸与したパソコンに、情報システム部の許可なくソフトウェアをインストールしないこと。
3. 業務用のチャットツール「ユキミチ」で連絡を受けたときは、勤務時間内であれば2時間以内に返信すること。

### 第5条(副業)

1. 従業員は、会社に届け出て承認を受けた場合に限り、副業をすることができる。
2. 届出は副業を始める日の1か月前までに人事部へ提出する。会社は届出を受けた日から2週間以内に、承認するかどうかを回答する。
3. 副業の時間は、1か月あたり40時間を上限とする。
4. 会社と競合する事業を行う会社での副業は認めない。

## 第3章 勤務時間・休日

### 第6条(勤務時間)

1. 所定の勤務時間は、始業9時30分、終業18時15分とし、そのうち休憩時間を60分とする(1日の実働は7時間45分)。
2. 会社はフレックスタイム制を採用する。コアタイムは11時から15時までとし、この時間は勤務していなければならない。
3. フレックスタイム制の清算期間は1か月とし、毎月1日を起算日とする。

### 第7条(休憩)

1. 休憩時間は原則として12時から13時までとする。業務の都合で、所属長の承認を得て時間をずらすことができる。
2. 時間外労働が2時間を超える日は、2時間を超えた時点で15分の休憩を追加で取らなければならない。

### 第8条(休日)

休日は次のとおりとする。

1. 土曜日と日曜日
2. 国民の祝日
3. 年末年始(12月29日から1月4日まで)
4. 会社の創立記念日(6月14日)

### 第9条(時間外労働)

1. 時間外労働をするときは、前日の17時までに勤怠システム「トモシビ」で申請し、所属長の承認を得なければならない。
2. 当日に急な対応が必要になった場合は、時間外労働を始める前にチャットで所属長に連絡し、翌営業日までに「トモシビ」で申請する。
3. 時間外労働は、1か月あたり30時間を社内の上限とする。30時間を超える見込みのときは、所属長が部長の承認を得なければならない。

### 第10条(在宅勤務)

1. 従業員は、所属長の承認を得て、1週間あたり3日まで在宅勤務をすることができる。
2. 在宅勤務をする週の前週の金曜日17時までに、「トモシビ」で予定を申請する。
3. 入社後、試用期間中の従業員は在宅勤務をすることができない。
4. 在宅勤務手当は、給与規程で定める。

### 第11条(遅刻・早退・欠勤)

1. 遅刻・欠勤をするときは、コアタイムが始まる11時までに「ユキミチ」で所属長に連絡する。
2. 病気による欠勤が連続して4日以上になるときは、医師の診断書を提出する。

## 第4章 休暇

### 第12条(年次有給休暇の付与)

1. 入社日から3か月が経過した従業員に、年次有給休暇を10日付与する。
2. 2回目以降は毎年4月1日に付与する。付与日数は、2回目が12日、3回目が14日とし、以後1回ごとに2日ずつ増やして最大22日とする。
3. 使い切らなかった年次有給休暇は翌年度に繰り越せる。ただし、繰り越した日数と新たに付与した日数の合計は、最大35日とする。

### 第13条(年次有給休暇の取得手続き)

1. 年次有給休暇を取るときは、取得日の3営業日前までに「トモシビ」で申請する。
2. 急な病気などでやむを得ない場合は、当日の11時までに所属長に連絡し、出勤した日に事後申請することができる。
3. 年次有給休暇は、1日単位のほか、半日単位と1時間単位で取ることができる。1時間単位で取れるのは1年度あたり40時間(5日分)までとする。

### 第14条(特別休暇)

従業員は、次の場合に有給の特別休暇を取ることができる。

| 事由 | 日数 | 取得できる期間 |
|---|---|---|
| 本人の結婚 | 7日 | 婚姻届を出した日から1年以内 |
| 配偶者の出産 | 3日 | 出産予定日の2週間前から出産後2か月以内 |
| 父母・配偶者・子の死亡 | 5日 | 死亡した日から10日以内 |
| 祖父母・兄弟姉妹の死亡 | 2日 | 死亡した日から10日以内 |

### 第15条(誕生日休暇)

1. 従業員は、誕生日のある月とその翌月のうちの1日を、有給の誕生日休暇として取ることができる。
2. 期間内に取らなかった誕生日休暇は、繰り越すことができない。

### 第16条(リフレッシュ休暇)

1. 勤続5年、10年、15年、20年を迎えた従業員に、有給のリフレッシュ休暇を5日付与する。
2. リフレッシュ休暇は、勤続年数を迎えた日から1年以内に、連続して取らなければならない。
3. リフレッシュ休暇を取る従業員には、給与規程で定めるリフレッシュ支援金を支給する。

## 第5章 退職

### 第17条(退職の手続き)

1. 従業員が自己の都合で退職するときは、退職日の45日前までに退職届を人事部に提出する。
2. 退職日までに、貸与されたパソコン・社員証・入館カードを情報システム部に返却する。

## 第6章 別規程

### 第18条(別規程)

次の事項は、別の規程で定める。

1. 給与に関する事項: 給与規程
2. 出張と旅費に関する事項: 旅費規程
3. 育児休業・介護休業に関する事項: 育児・介護休業規程
