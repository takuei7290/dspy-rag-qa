# 株式会社しろくま堂システムズ 旅費規程

> この文書は、QAボットの学習用に作成した架空の会社の規則です。実在の会社・規則とは関係ありません。

### 第1条(目的)

この規程は、就業規則第18条にもとづき、従業員が業務で出張するときの手続きと旅費に関する事項を定める。

### 第2条(出張の定義)

この規程で出張とは、所属する事業所から片道60km以上離れた場所で業務を行うこと、または宿泊を伴う業務をいう。片道60km未満の移動は外出とし、交通費のみを経費精算システムで精算する。

### 第3条(出張の申請)

1. 国内に出張するときは、出発日の5営業日前までに出張申請書を所属長に提出し、承認を得る。
2. 海外に出張するときは、出発日の30日前までに出張申請書を提出し、所属長と部長の承認を得る。

### 第4条(交通手段)

1. 出張の交通手段は、原則として鉄道・バスなどの公共交通機関とする。
2. 新幹線と特急列車は、普通車の指定席を利用する。
3. 鉄道での所要時間が片道4時間を超えるときは、航空機を利用できる。航空機はエコノミークラスとする。

### 第5条(タクシーの利用)

タクシーは、次のいずれかにあたる場合に限り利用できる。

1. 22時から翌朝6時までの間に移動するとき
2. 10kg以上の機材を運ぶとき
3. 公共交通機関が運休しているとき

### 第6条(宿泊費)

宿泊費は、1泊あたり次の金額を上限として実費を支給する。

| 地域 | 上限 |
|---|---|
| 東京23区・大阪市・名古屋市 | 12,000円 |
| その他の国内 | 9,500円 |
| 海外 | 25,000円 |

### 第7条(日当)

出張中の食事などの費用として、次の日当を支給する。

| 区分 | 日当 |
|---|---|
| 国内の日帰り出張(片道100km以上の場合に限る) | 1,500円 |
| 国内の宿泊を伴う出張 | 1日あたり2,500円 |
| 海外出張 | 1日あたり5,000円 |

### 第8条(仮払い)

1. 旅費が5万円以上になる見込みのときは、仮払いを申請できる。
2. 仮払いは、出発日の3営業日前までに経費精算システムで申請する。

### 第9条(旅費の精算)

1. 旅費は、出張から帰った日の翌日から14日以内に、領収書を添えて経費精算システムで精算する。
2. 期限を過ぎて精算するときは、遅れた理由を書いて部長の承認を得なければならない。
3. 仮払いを受けた場合は、精算のときに差額を返金、または追加で受け取る。

### 第10条(マイル・ポイント)

出張で貯まった航空会社のマイルや交通系のポイントは、個人のものとしてよい。ただし、マイルやポイントを貯めるために、より高い運賃の便や経路を選んではならない。
