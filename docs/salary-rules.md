# 株式会社しろくま堂システムズ 給与規程

> この文書は、QAボットの学習用に作成した架空の会社の規則です。実在の会社・規則とは関係ありません。

### 第1条(目的)

この規程は、就業規則第18条にもとづき、従業員の給与に関する事項を定める。

### 第2条(給与の構成)

給与は、基本給、諸手当(通勤手当・在宅勤務手当・資格手当・家族手当)、時間外手当で構成する。

### 第3条(締め日と支払日)

1. 給与は毎月20日に締め、その月の28日に支払う。
2. 28日が休日にあたるときは、その直前の営業日に支払う。
3. 給与は、従業員が指定した本人名義の銀行口座に振り込む。

### 第4条(通勤手当)

1. 通勤手当は、自宅から事業所までの最も経済的な経路の定期券代を実費で支給する。上限は1か月あたり5万円とする。
2. 在宅勤務の日数が1か月に12日以上ある月は、定期券代ではなく、実際に出社した日の往復運賃を支給する。

### 第5条(在宅勤務手当)

1. 在宅勤務をした日1日につき、在宅勤務手当として300円を支給する。
2. 在宅勤務手当の上限は、1か月あたり3,600円とする。

### 第6条(資格手当)

1. 次の資格を持つ従業員に、資格手当を毎月支給する。複数の資格を持つときは、最も金額が高いもの1つのみを支給する。

| 資格 | 月額 |
|---|---|
| 基本情報技術者 | 3,000円 |
| 応用情報技術者 | 8,000円 |
| 高度情報処理技術者(ネットワークスペシャリストなど) | 15,000円 |

2. 資格手当は、合格証書の写しを人事部に提出した月の翌月から支給する。
3. 上の表の資格の受験料は、合格したときに限り、会社が1回分を負担する。

### 第7条(家族手当)

1. 扶養している配偶者がいる従業員に、月額10,000円を支給する。
2. 扶養している子がいる従業員に、子1人につき月額8,000円を支給する。子が22歳になった年度の3月まで支給する。

### 第8条(時間外手当)

時間外手当は、1時間あたりの基本給に、次の割増率をかけて計算する。

| 区分 | 割増率 |
|---|---|
| 所定の勤務時間を超えた労働 | 1.30 |
| 1か月の時間外労働が45時間を超えた部分 | 1.50 |
| 休日の労働 | 1.40 |
| 深夜(22時から翌朝5時まで)の労働 | 上の割増率に0.30を加える |

### 第9条(賞与)

1. 賞与は、年2回、7月10日と12月10日に支給する。
2. 7月の賞与は前年10月1日から3月31日まで、12月の賞与は4月1日から9月30日までの勤務を評価の対象とする。
3. 支給日に在籍していない者には、賞与を支給しない。

### 第10条(昇給)

昇給は年1回、4月の給与から行う。昇給額は、前年度の人事評価をもとに決める。

### 第11条(リフレッシュ支援金)

就業規則第16条のリフレッシュ休暇を取った従業員に、リフレッシュ支援金を支給する。金額は勤続5年で5万円、勤続10年以上で10万円とし、休暇を取った月の翌月の給与と合わせて支払う。

### 第12条(書籍購入補助)

1. 業務に関係する書籍・技術書を購入したときは、1か月あたり5,000円まで会社が補助する。
2. 補助を受けるときは、購入日から30日以内に領収書を添えて経費精算システムで申請する。
3. 補助を受けて購入した書籍は個人の所有とする。
